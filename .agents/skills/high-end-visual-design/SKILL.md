# High-End Visual Design (taste-skill)

1. **Typography Scale & Contrast**: Few sizes, far apart (Display, Section Heading, Lead, Body, Small/Caption). Display type uses tight tracking (`-0.02em` to `-0.04em`), line-height `0.92–1.05`, and `text-wrap: balance`. Body text uses `16–18px`, line-height `1.5`, and measure `45–68ch`. Tabular numerals (`tabular-nums`) for prices, stock counts, and order tables.
2. **Colour Proportions**: Ground (`--bg` / cream) carries 75–85% of the viewport; Ink (`--ink` / primary) carries typography and primary actions; Accent (`--accent` / warm sand-caramel) is reserved for key interactive highlights (<5% of screen); Sale (`--sale`) only for genuine price/campaign tags.
3. **Surfaces Without Clutter**: Separate surfaces using subtle tone steps (`--surface`) or clean editorial hairlines where appropriate for tables/forms, avoiding generic SaaS drop shadows, gradient blobs, or floating pill navbars.
4. **Photography as Hero**: Consistent `3:4` aspect ratio for fashion product cards and galleries, neutral warm stone placeholders, no badges overlapping model faces, and full-bleed or asymmetrical editorial framing.
